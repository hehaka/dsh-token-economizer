## Facts

- Route at `agent/created` (verified live): `agent.options.provider` = `'anthropic'`, `agent.options.model` = `'claude-haiku-5-5'`, i.e. `observeRoute(agent.options)` in `plugin.mjs` works as written. Type: `AgentOptions { provider?: string; model?: string; reasoningEffort?; maxTokens?; subagentDepth? }` (`dsh-agent/lib/types/runtime-types.d.ts:21`); both fields are optional in the type, present in this run.
- Where it comes from in headless: `dsh-headless` passes `agentOptions = { provider, model }` from `agentDefaultModel.currentSelection()` to `agents.create(...)` (`dsh-headless/lib/index.js:297-303`); the web/api session controller does the same (`dsh-api-session-controller/lib/index.js:527-528`). `agent.options` is the creation-time route; a later model switch is reflected in the logged request header (`request/header` `data.header.config.provider/model`, `request/context` `data.provider/model`), not in `agent.options`. `dsh-subagent` itself prefers the parent's logged request config over `parent.options` for delegation (`index.js:293-303`).
- Not carrying a route: `agent.session.header` (version,id,createdAt,cwd,isSeeded; subagents add parentSession,origin,delegationDepth,agentPreset,cwd), the `session/created` payload header, `agent.ctx` own keys, `agent` itself (other than `agent.options`).
- Independent route source without a request: service `agentDefaultModel`, `currentSelection() -> {provider, model, reasoningEffort?}`, via `ctx.inject(['agentDefaultModel'], c => c.agentDefaultModel)` (verified: injected before `session/created`; returned the same pair at `agent/created`). It is the profile default, not necessarily the model of a resumed or switched session.
- Event arrival (one run): `session/created` > `permission/preset`,`sandbox/mode`,`approval/policy` > `agent/created` (+55 ms) > ... > `request/header` > `request/context` (+383 ms). Our `session/created` handler (SessionStart) runs before any route is observable.
- Caveat on the diagnostic: the `agent.agent.options...` path in `q1.log.jsonl`'s `modelish` field is an artifact of the diagnostic wrapping `{agent}`; the real path is `agent.options.*`.
